# Publish to GitHub

Suggested repository name: `virage-change`.

The project is ready to publish as a public repository. Do not commit `.env` or `data/`; both are ignored. `public/` is generated by `npm run build` and is intentionally ignored.

With GitHub CLI on your own machine:

```bash
git init
git add .
git commit -m "Initial public Virage Change reconstruction"
git branch -M main
gh repo create virage-change --public --source=. --remote=origin --push
```

Without GitHub CLI, create an empty public repository in GitHub, then add it as `origin` and push `main`.
