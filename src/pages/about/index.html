Интерфейс строится вокруг точных цифр, круглых форм и спокойного слоя жидкого стекла.

Принцип

Фон не двигает вёрстку, стекло используется только на плавающих слоях, а интерфейс остаётся спокойным и предсказуемым.

Архитектура

Публичная версия на GitHub Pages работает как статическая витрина без сервера. Серверный контур Node.js 22 остаётся в репозитории для локального или отдельного хостинга.
